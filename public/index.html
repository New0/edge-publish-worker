This is the placeholder page that ships with a fresh deployment. It is replaced the moment your site sends its first page.

  1. Copy this deployment's address into the Edge Publish plugin, under Settings → Endpoint.
  2. Paste the same shared secret you set as SYNC_SECRET here.
  3. Press Test connection, then Resync the whole site.

If you are seeing this page after a resync, the pages went somewhere else — check that the endpoint in the plugin is this address.
